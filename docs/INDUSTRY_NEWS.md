# Snowmobile Industry News

## Route

The public page lives at `/snowmobile-industry-news`.

## Published Data

Published roundup data is stored in `src/data/industry-news.json`.

The page renders the latest valid roundup first and keeps older roundups in the archive. If no verified roundup is published, the page shows a safe empty state instead of placeholder or fictional stories.

## Source Configuration

Candidate sources are configured in `src/data/industry-news.sources.json`.

Sources can be added, removed or disabled by editing that file. Prefer official manufacturer announcements, government recall notices, racing organizations, associations and established snowmobile or powersports trade publications.

## Ranking

The weekly update workflow uses these ranking criteria:

- Industry impact
- Snowmobile relevance
- Source authority
- Recency
- Originality
- Market reach
- Safety or regulatory importance

Editors must store final ranks explicitly in `src/data/industry-news.json`.

## Thumbnails

Thumbnails are generated by the page from each story category and `thumbnailVariant`. They are deterministic, original SVG compositions and do not use publisher photography, logos or screenshots.

## Weekly Update

The GitHub Actions workflow `.github/workflows/industry-news.yml` runs every Monday at `15:00 UTC`, which is Monday morning in `America/Denver`.

The workflow runs:

```bash
node scripts/update-industry-news.mjs
node scripts/validate-industry-news.mjs
```

The update script creates a local candidate audit file at `src/data/industry-news.candidates.json`. That file is ignored by Git and is intended for editorial review. The script does not automatically publish unverified stories.

Run the workflow locally with:

```bash
pnpm run news:update
pnpm run news:validate
```

## Publishing a Roundup

To publish a weekly roundup:

1. Review direct original source links.
2. Add verified stories to `src/data/industry-news.json`.
3. Set `latestRoundupDate` to the new roundup `weekOf` date.
4. Keep previous roundups in the `roundups` array.
5. Run `pnpm run news:validate`.
6. Run `pnpm run lint` and `pnpm run build`.

## Failure Recovery

Failed update runs do not modify `src/data/industry-news.json`, so the previous valid roundup remains available. If a published roundup fails validation, fix the data or reset `latestRoundupDate` to the previous valid `weekOf` date.

## Environment Variables

No secrets are required for the current Version 1.0 workflow.

If a future synopsis provider is added, credentials must remain server-side and be documented in the project environment example without committing real values.
